## Commands

Package manager is **pnpm** (see `packageManager` in package.json) — do not use npm/yarn.

- `pnpm dev` — start the dev server (http://localhost:3000)
- `pnpm build` — production build
- `pnpm start` — serve the production build
- `pnpm lint` — run ESLint (flat config, `eslint.config.mjs`)

No test runner is configured.

## Architecture

- **Next.js 16.3.3** (App Router) + **React 19** + **Tailwind CSS v4** + TypeScript.
- App Router lives in `app/`: `layout.tsx` (root layout, fonts, metadata), `page.tsx` (landing page), `globals.css`.
- **Tailwind v4 is CSS-first** — there is no `tailwind.config.js`. Theme tokens, custom colors, and animation keyframes are declared in `app/globals.css` via `@import "tailwindcss"`, `@theme inline { ... }`, and `@keyframes`. Add design tokens there, not in a JS config.
- **Next 16 generates route types** — e.g. `LayoutProps<"/">` in `app/layout.tsx` is auto-provided. Don't hand-write these prop types.
- The landing page (`app/page.tsx`) is a **server component with pure-CSS animations** (no `"use client"`). Starfield positions are computed deterministically at module load so server/client markup matches — keep that pattern if adding more generated visuals, or hydration will mismatch.

## Notes for Next.js work
